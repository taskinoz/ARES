# Skills

Mirrored from `.agents/skills/` by `scripts/sync-agent-skills.py`.
Edit the canonical copies there, then run the script.

- [accept-northstar-map](accept-northstar-map/SKILL.md): Run release acceptance on a Titanfall 2 / Northstar map mod in the game. Probes every spawn in Pilots vs Pilots and Free For All, respawns both teams, fires a weapon, goes through postmatch to the lobby and reloads after a stock map, with clean logs. Use before publishing or installing a new map version.
- [add-tf2-cubemaps](add-tf2-cubemaps/SKILL.md): Give a Titanfall 2 map reflection cubemaps captured in the game itself. Plan the origins, capture six HUD-free views per origin through the Northstar harness, then write the BC6H VTF, pakfile and per-mesh assignments. Use when a compiled or converted map has no cubemaps (metal and wet surfaces reflect nothing).
- [add-tf2-prop-shadows](add-tf2-prop-shadows/SKILL.md): Make a Titanfall 2 map's static props cast real-time sun (cascaded) shadows by listing them in the CSM object tree. Use when a map's props shadow the baked lightmaps but not players or each other (the CSM tree, lumps 0x63/0x64, is empty).
- [build-map](build-map/SKILL.md): Build or convert a Respawn map and verify it with a static-then-runtime loop. Use when compiling a .map with MRVN-Radiant's remap, converting another game's map, or iterating on a map fix until it works in game.
- [build-navmesh](build-navmesh/SKILL.md): Select and validate Recast navigation workflows for Titanfall 2 or Apex maps. Use when baking or investigating navmeshes, coordinate transforms, agent bounds or game-specific navigation export; not for TF1/TFO node graphs.
- [compile-model](compile-model/SKILL.md): Compile models with the registered Respawn compilers and validate the output with ARES readers and harnesses.
- [convert-assets](convert-assets/SKILL.md): Convert assets across supported workflows while preserving provenance.
- [deploy-goldhen-plugin](deploy-goldhen-plugin/SKILL.md): Install a plugin or mod files on a real PS4 running GoldHEN over FTP, enable it in plugins.ini, record the kernel log and summarise the last boot or crash, with the ARES GoldHEN adapter. Use to test a PS4 homebrew plugin or port (e.g. PS4 Northstar) on hardware, or to diagnose a console crash from the kernel log.
- [discover-tools](discover-tools/SKILL.md): Discover ARES tools and upstream runtime, scripting and navigation sources by game and capability. Use to select a compiler, harness, runtime fork or Recast tool without assuming cross-fork compatibility.
- [inspect-bsp](inspect-bsp/SKILL.md): Statically inspect and validate Respawn BSP maps (Titanfall 1 v29, Titanfall 2 v37, Apex v47) and their RPak/VPK/STBSP packages with the ARES format tools. Use before any runtime test, to diagnose a map that crashes or misbehaves, or to compare a compiled map against a retail one.
- [inspect-respawn-model](inspect-respawn-model/SKILL.md): Read and check Respawn model files (MDL v52/v53, RMDL v54, IVP and Apex PHY, Apex BVH) with the ARES readers. Use before and after compiling or converting a model, to identify a file's version, or to check physics and collision data.
- [optimise-tf2-map](optimise-tf2-map/SKILL.md): Shrink and check a compiled or converted Titanfall 2 (BSP v37) map. Weld duplicated triangle-collision and sun-shadow positions, check the world drawing budget, and find visibility cells that hide entities. Use after a map build or conversion, when a map file is unexpectedly large, or before a release.
- [publish-thunderstore](publish-thunderstore/SKILL.md): Check a Thunderstore package ZIP's layout and publish it with Thunderstore's multipart, background-validated upload. Use when releasing a Northstar (or other Thunderstore community) mod or map package, including large packages where the official CLI's synchronous finalize fails.
- [research-engine](research-engine/SKILL.md): Investigate engine behaviour and document evidence-backed findings.
- [reverse-engineer-prx](reverse-engineer-prx/SKILL.md): Find and verify functions, globals, vtables and ConCommands in decrypted PS4 modules (.prx, eboot.bin) or x86-64 ELFs with the ARES prx_inspect tool - strings to code xrefs, relocated pointer tables, byte patterns, disassembly - and check RPak texture platforms and pdef layouts for ports. Use when porting a Respawn game or mod to PS4, matching a PC function to its PS4 counterpart, or explaining a crash address.
- [run-harness](run-harness/SKILL.md): Load a map or mod in a real Respawn game (Titanfall 2/Northstar or Ion, Titanfall Online, R1Delta, R5Reloaded, R5Flowstate) and run traces, spawn probes, physics drops and screenshots through the ARES harnesses. Use when a map, mod or conversion must be proven to work in the engine, not only to parse.
- [test-northstar](test-northstar/SKILL.md): Load compiled Titanfall 2 models in the game through Northstar with the ARES harness - spawn, sequences, attachments, root motion, physics drops, NPC ragdolls and screenshots. Use to get runtime evidence for R2 models.
- [test-northstar-mod](test-northstar-mod/SKILL.md): Test a Titanfall 2 Northstar gameplay mod or gamemode (scripts, timers, records, HUD, triggers) in the real game with the ARES Northstar Session API, using an isolated profile and an instrumented copy of the mod. Use when a mod's behaviour must be verified natively rather than by reading Squirrel code.
- [test-r5reloaded](test-r5reloaded/SKILL.md): Package Apex (S3) models with RePak and test them in an isolated R5Reloaded copy - spawning, sequences, attachments, trace collision, physics drops and ragdolls - with the ARES harness. Use to get runtime evidence for R5 models.
- [test-shadps4](test-shadps4/SKILL.md): Boot a PS4 game or mod in the shadPS4 emulator and prove it reached a state, with log patterns, pad input, screenshots, black-screen checks and guest memory reads, using the ARES shadPS4 adapter. Use to test a PS4 port, plugin or mod change (e.g. PS4 Northstar), to reproduce a crash or black screen, or to read a live value at module+offset.
- [test-titanfall1](test-titanfall1/SKILL.md): Runtime-test MDL v52 models in Titanfall Online (TFORevive) and in original Titanfall through R1Delta - staging, telemetry, collision and physics probes, retail-versus-rebuilt comparison - with the ARES harnesses. Use to get runtime evidence for R1 and TFO models.
- [validate-r5-collision](validate-r5-collision/SKILL.md): Check and compare Apex Legends (S0-S3) physics (PHY) and trace collision (BVH) of a rebuilt or converted model against the original, with fixed limits. Use when compiling, converting or porting R5 models with collision.
